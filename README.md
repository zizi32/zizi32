## RESPONSIBLE DISCLOSURE PRINCIPLES

My workflow follows a strict, non-destructive protocol:

```

DISCOVER
↓
MINIMAL VERIFICATION
↓
DOCUMENT
↓
PRIVATE REPORT
↓
COORDINATION
↓
REMEDIATION

```

### Core Values
- **Minimize access** – Only interact with what is necessary to confirm the issue.
- **Avoid exploitation** – Do not use the finding beyond verification.
- **Respect boundaries** – Operate only within authorized scope and programs.
- **Private reporting** – Always report directly to the system owner or responsible team.
- **Allow remediation** – Give system owners time to investigate and fix the issue before disclosure.
