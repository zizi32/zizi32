## RESPONSIBLE DISCLOSURE PRINCIPLES

My workflow follows a disciplined, non-destructive approach:

```

DISCOVER
↓
MINIMAL VERIFICATION
↓
DOCUMENT
↓
PRIVATE REPORT
↓
COORDINATION
↓
REMEDIATION

```

**My approach:**
- Minimize access and avoid unnecessary exploitation.
- Do not download or distribute sensitive information.
- Respect authorization boundaries.
- Report vulnerabilities privately.
- Allow system owners to investigate and remediate.
